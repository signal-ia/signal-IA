# SIGNAL

Rehausseur audio pour Warzone — mieux entendre les pas et déplacements ennemis en jeu.

## Téléchargement

La dernière version est disponible dans l'onglet **[Releases](https://github.com/signal-ia/signal-IA/releases)** de ce dépôt.

## Installation

1. Téléchargez le fichier `SIGNAL_Setup_vX.X.X.exe` depuis la dernière release
2. Lancez l'installateur et suivez les étapes

   > ⚠ Si Windows affiche un écran bleu "Windows a protégé votre ordinateur" : c'est normal pour un logiciel indépendant, ce n'est pas un virus. Cliquez sur "Informations complémentaires", puis sur "Exécuter quand même". Cet écran n'apparaît qu'à la première installation.

3. Au premier lancement, entrez votre clé de licence lorsque demandé

## Mises à jour

SIGNAL vérifie automatiquement les mises à jour à chaque lancement et propose de les installer.
